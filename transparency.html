Вставьте ссылку на товар из белого списка — сервер примет задачу. В режиме Соло задачи хранятся только на этом ПК. Мониторинг ≠ биржа (авантюрист): это разные уровни риска.

Режимы: Соло · Воркер · Premium

  • Соло — локальные задачи в браузере, без облака; виджет сравнения недоступен
  • Воркер — облачные задачи + P2P-проверки цен по whitelist; виджет сравнения
  • Premium — облако без P2P; не продаётся, выдаётся за достижения (рефералы / топ / донат)

Какие данные отправляются на сервер

  • Telegram ID — привязка и уведомления
  • Ссылка / ID товара — только whitelist
  • Целевая цена и результат проверки (цена, title, EAN если есть)

Не собираем: пароли, cookies магазинов, историю браузера, содержимое других вкладок, карты.

Токен сессии хранится только на этом ПК (chrome.storage.local), не в Chrome Sync.

Режим воркера (P2P) — добровольно

В idle расширение открывает фоновую вкладку с товаром из очереди в вашей сессии браузера (если вы залогинены в Ozon/WB — вкладка идёт как обычный визит с вашими cookies браузера; само расширение cookies не читает и не выгружает).

  • Читает публичную цену со страницы
  • На сервер уходит только результат проверки (цена / ошибка)

Выключить воркер можно в любой момент. Свободный серфинг не журналируется.

Ссылки и CPA

Сейчас тихая подмена ссылок на страницах магазинов выключена (пока нет партнёрских шаблонов на сервере). Виджет «дешевле» может показать кнопку с другой ссылкой — это явный клик, не скрытая подмена всех ссылок.

Авантюрист (биржа) — отдельный уровень риска

По умолчанию биржа выключена на сервере. Если когда-то включите сами:

  • Нужно явное согласие в popup
  • Скрипт по заданию сервера может кликать и печатать на выбранных сайтах
  • Это не мониторинг цен — выше риск для аккаунтов на сайтах

Без согласия авантюриста расширение этого не делает.

Обновления

Расширение не из Chrome Web Store. Новые версии скачиваются с halyavka.online/extension/ (version.json + zip). Исходники и CHANGELOG — в открытом репозитории. В popup: «Отвязать этот ПК» сбрасывает токен на устройстве.
