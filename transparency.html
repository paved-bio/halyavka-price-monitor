Какие данные отправляются на сервер

  • Telegram ID — для привязки аккаунта и уведомлений
  • Ссылка / ID товара — только из белого списка магазинов
  • Целевая цена — порог для уведомления
  • Результат проверки — цена, название, EAN (если найден на странице)

Не собираем: пароли, cookies магазинов, историю браузера, содержимое других вкладок, данные банковских карт.

Подписка или воркер

  • До 100 товаров из разных магазинов whitelist одновременно
  • Триал ~30 дней — бесплатно с режимом воркера
  • Воркер (бесплатно) — ваш ПК помогает сети читать цены с whitelist-страниц в idle (>5 мин)
  • Подписка ~100 ₽/мес — мониторинг без нагрузки на ПК; проверяют другие воркеры

Режимы «цена ниже X» и «появится в наличии» (в т.ч. билеты Tutu на маршрут).

Режим воркера (P2P) — добровольно

Если включите воркер, расширение только когда вы не за компьютером (idle > 5 мин):

  • Открывает фоновую вкладку с чужим товаром из очереди
  • Читает публичную цену со страницы (как обычный посетитель)
  • Отправляет только цену на наш сервер

Воркер можно выключить в любой момент. Без воркера (или с платной подпиской) ваши товары проверяют другие воркеры.

Открыть очередь воркера — что сейчас мониторит сеть (без имён и скрытых сайтов).
