# Безопасность Price Monitor

Исходный код расширения открыт для проверки. Ниже — что расширение **может** и **не может** делать.

Полный список магазинов и модель whitelist: **[WHITELIST.md](WHITELIST.md)**

## Чего расширение не делает

- **Не читает клавиатуру** и не перехватывает ввод паролей
- **Не имеет доступа** к файлам на диске
- **Не открывает произвольные сайты** — только домены из whitelist задачи
- **Не шлёт** cookies/пароли на сервер — только результат проверки (цена, наличие, название)

## Мониторинг цен — только whitelist

- Пользователь **не может** добавить ссылку вне белого списка: сервер вернёт ошибку 400
- Воркер **не может** получить задачу на чужой домен: URL собирается сервером из `SAFE_SHOPS`
- Расширение проверяет URL перед открытием вкладки (`shop_url_guard.js`), в т.ч. редирект Ozon на `/search/`
- **12 магазинов:** Ozon, WB, Steam, Avito, Tutu, Яндекс Маркет, DNS, Золотое Яблоко, Ситилинк, М.Видео, Детский мир, Лемана ПРО
- Только чтение публичной цены/наличия; вкладка помечается полосой «Халявка · проверка цены»
- Цена записывается после отчёта воркера (при нескольких воркерах — консенсус; при одном — solo-режим на сервере)

## Воркер или Premium

- **Триал ~30 дней** — добавление товаров и режим воркера
- **Воркер (бесплатно)** — ваш ПК помогает сети парсить whitelist, когда вы не за компьютером (idle)
- **Premium** — облако без воркера; **не продаётся** в приложении, выдаётся за достижения (рефералы / топ / донат)

## Режим «Авантюрист» (биржа) — отдельно

- Только если вы включили earn и **сами выбрали категории** в настройках
- Перед переходом проверка URL в `category_hosts.js`
- Отчёт подписывается HMAC; сервер отклоняет подделки

## Прозрачность в UI

- Popup: список магазинов, ссылка на GitHub и `transparency.html`
- `worker_info.html` — публичная очередь (магазины и типы, без имён)
- Сайт: [halyavka.online/extension/](https://halyavka.online/extension/)

## Что проверить при аудите

1. [`WHITELIST.md`](WHITELIST.md) и [`constants.js`](constants.js) — список магазинов
2. [`shop_url_guard.js`](shop_url_guard.js) — блокировка неверных URL (Ozon search/journey)
3. [`background.js`](background.js) → `parseViaBackgroundTab` — только URL из задачи
4. [`category_hosts.js`](category_hosts.js) — биржа: домен ↔ категория
5. [`manifest.json`](manifest.json) — `host_permissions` совпадают с whitelist

## Апелляции

Если воркер или биржа приостановлены ошибочно — апелляция через бота: **Отзывы → Апелляция**.
