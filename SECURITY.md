# Безопасность Price Monitor

Исходный код расширения открыт для проверки. Ниже — что расширение **может** и **не может** делать.

## Чего расширение не делает

- **Не читает клавиатуру** и не перехватывает ввод паролей
- **Не имеет доступа** к файлам на диске
- **Не работает постоянно** — только когда вы включили воркер/биржу и ПК в idle (или принудительный тест)
- **Не открывает сайты** без задания с сервера
- **Не шлёт** cookies/пароли на сервер — только результат задачи (цена, лайк подтверждён, и т.д.)

## Режим «Воркер» (мониторинг цен)

- Только домены из **белого списка**: Ozon, Wildberries, Steam, Avito, Tutu (+ тестовые mock)
- Только чтение публичной цены/наличия
- Цена принимается по **консенсусу 3 воркеров** — один «хитрец» не меняет результат
- Вкладка помечается полосой «Халявка · проверка цены»

Список доменов воркера: `price-monitor/server.py` → `SAFE_SHOPS`.

## Режим «Авантюрист» (биржа)

- Вы **сами выбираете категории** в настройках (`/earn/`) — на сервер уходят только галочки
- Сервер выдаёт job **только** из выбранных категорий
- Перед переходом расширение проверяет URL по `category_hosts.js` — например, `vk_like` **только** vk.com
- Категория **«Нетипичные сайты»** (`custom_site_crawl`) — отдельная галочка, повышенный риск, opt-in
- Вкладка помечается полосой «Халявка · задача биржи»
- Отчёт подписывается HMAC; сервер отклоняет подделки и ведёт strikes

## Прозрачность в UI

- Popup расширения: список магазинов и ссылка на этот документ
- Во время задачи — видимая полоса на вкладке
- Сайт: [halyavka.online/extension/](https://halyavka.online/extension/), [halyavka.online/exchange/](https://halyavka.online/exchange/)

## Репозиторий

Публичный исходный код **только расширения**: [github.com/paved-bio/halyavka-price-monitor](https://github.com/paved-bio/halyavka-price-monitor)

URL в popup подгружается с сервера (`PM_REPO_URL` → `/api/v1/meta/public`). Сервер, бот и админка в закрытом репозитории — в расширении нет секретов доступа к ним.

## Что проверить при аудите

1. `category_hosts.js` — соответствие домена и категории
2. `background.js` → `runEarnBatch` — проверка `can_earn` и `earn_allowed_categories`
3. `background.js` → `processOneEarnJob` — `isUrlAllowedForCategory` перед `tabs.create`
4. `scenario_runner.js` — только declarative actions, без произвольного JS
5. Поиск по репозиторию на типичные секреты — совпадений с реальными ключами нет

## Апелляции

Если биржа или воркер приостановлены ошибочно — апелляция через бота: **Отзывы → Апелляция**. Полный бан аккаунта (бот/подписки) этим не снимается.
