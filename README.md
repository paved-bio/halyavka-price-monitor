# Price Monitor — расширение Chrome (открытый исходный код)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

Браузерное расширение для [halyavka.online](https://halyavka.online): мониторинг цен на маркетплейсах и **добровольное** участие в бирже микрозадач («авантюрист»).

> **Этот репозиторий содержит только код расширения.**  
> Сервер, бот, админка и база данных — в закрытом репозитории оператора.  
> В исходниках расширения **нет** паролей админки, API-секретов сервера и доступа к чужим аккаунтам.

---

## Главный принцип: только с вашего согласия

| Действие | Без вашего действия | После вашего согласия |
|----------|---------------------|------------------------|
| Мониторинг цен | Не работает | Вы сами добавили товар + URL |
| Биржа (earn) | **Не работает** | Вы приняли условия + **отметили категории** в popup |
| Открытие сайтов | Расширение **не** ходит по интернету само | Только URL из задачи сервера **и** из ваших галочек |
| Пароли / cookies | **Не читаются, не отправляются** | — |

Проверка в коде:

1. **`popup.js` / `earn_prefs.js`** — категории хранятся локально и синхронизируются с сервером только когда вы нажимаете «Сохранить».
2. **`background.js` → `runEarnBatch()`** — если `can_earn === false` или список категорий пуст → `skipped: "earn_off"` / `"no_categories_selected"`.
3. **`background.js` → `processOneEarnJob()`** — перед открытием вкладки проверка `category_hosts.js`: URL должен совпадать с категорией (например, `vk_like` → только `vk.com`).
4. **Сервер** (не в этом репо) повторно фильтрует jobs по вашим категориям и лимитам.

Без галочки на категорию расширение **пропускает** job (`category_not_allowed`), даже если сервер ошибочно его выдал.

## Чего расширение не делает

- Не перехватывает ввод с клавиатуры и не ищет поля паролей
- Не читает `document.cookie` и не эксфильтрует сессии магазинов
- Не сканирует произвольные сайты — только домены из [`category_hosts.js`](category_hosts.js) для выбранной категории
- Не содержит захардкоженных секретов оператора (пароли админки, ключи API и т.д.)
- Не вызывает admin API — только `/api/v1/...` от имени **вашего** `session_token` (получаете через код из Telegram-бота)

Подробнее: [SECURITY.md](SECURITY.md) · страница в расширении: `transparency.html`

---

## Что отправляется на сервер

- **При привязке:** одноразовый код из Telegram → в ответ `session_token` (хранится локально в `chrome.storage`)
- **Мониторинг:** URL товара, целевая цена, результат парсинга (цена, название)
- **Биржа:** подписанный отчёт о задаче (HMAC с ключом, выданным сервером при consent) — цена, лайк, текст комментария **из сценария**, не произвольные данные со страницы

## Структура репозитория

| Файл | Назначение |
|------|------------|
| `manifest.json` | Разрешения Chrome (белый список host_permissions) |
| `background.js` | Service worker: очередь earn, воркер, API |
| `category_hosts.js` | **Белый список доменов по категории** — ключевой файл для аудита |
| `scenario_runner.js` | Исполнение declarative steps (клик, extract, scroll) |
| `popup.js` / `popup.html` | Настройки, категории, согласие |
| `integrity.js` | Подпись отчётов (ключ с сервера, не в исходниках) |
| `SECURITY.md` | Модель угроз и ограничения |

## Установка (разработка)

1. Chrome → `chrome://extensions` → «Режим разработчика»
2. «Загрузить распакованное» → папка с этим репозиторием
3. Привязка: Telegram-бот → код → popup расширения

Сборка zip для сайта делается в основном репозитории: `scripts/build-extension-installer.ps1`

## Аудит безопасности (кратко)

Перед публикацией проверено:

- ✅ Нет секретов в исходниках (только публичный URL API `https://halyavka.online/api/v1`)
- ✅ `session_token` — per-user, выдаётся сервером, не вшит в код
- ✅ Двойная фильтрация категорий (клиент + сервер)
- ✅ `eval_json_script` — это `JSON.parse` текста из `<script>` на странице, не `eval()` произвольного кода
- ⚠️ `optional_host_permissions: *://*/*` объявлены, но **нигде не запрашиваются** (можно удалить в будущем)
- ⚠️ `nativeMessaging` в manifest — для опционального нативного апдейтера Windows; в ядре расширения не используется

Публикация этого репозитория **не раскрывает** закрытый бэкенд, админ-пароли и данные пользователей.
